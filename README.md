# Srijita Birthday 💗

A mobile-first interactive birthday page made for GitHub Pages.

## Add the song
Put your music file here:

`assets/blue.mp3`

The page will show a small **Blue** music button. Mobile browsers do not allow reliable autoplay, so the song starts after the first tap on the heart or the music button.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Put your `blue.mp3` inside `assets/`.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select your main branch and `/ (root)`, then Save.
7. Share the generated GitHub Pages link with Srijita.

## Personalize
All visible text is in `index.html`. Replace the letter/reasons with your own memories if you want it more personal.
